# 1.3.2 헌금 통계 연결 수정

기존 데스크톱의 수입/지출 관리 및 거래 가져오기로 입력한 수입은, 예산이 약정헌금이어도 헌금 종류가 지정되지 않아 헌금 통계에서 빠질 수 있었습니다.

- 새 수입을 입력할 때 예산명과 활성 헌금 종류가 정확히 일치하면 보통예금/헌금수익 및 해당 헌금 종류에 자동 연결합니다. 그 외의 이름·내용은 추정하지 않습니다.
- 과거 입력은 자동 변경하지 않습니다. **통계 → 누락 헌금 연결 확인**에서 기간 내 미연결 수입을 보고, 실제 헌금인 항목을 선택해 연결합니다. 보통예금 외의 기존 자산 계정은 유지합니다. 종류·통장이 다르면 개별 확인에서 직접 지정합니다.
- 헌금이 아닌 일반 수입은 연결할 필요가 없습니다. 마감 연도는 자동 변경하지 않습니다.
- 원본 수입을 새로 만들지 않으며, 역분개와 재분류로 기존 수입 합계를 유지합니다. 일괄 연결 중 하나라도 잘못되면 전체를 롤백합니다.
- 필터 결과가 0일 때 헌금자·종류를 전체로 되돌리는 버튼과 미연결 수입 확인 버튼을 제공합니다.

## 사용 방법

1. 기존 앱에서 백업하고 1.3.2 실행본을 별도 폴더에 압축 해제합니다. 기존 자료는 앱의 백업 복원 기능으로 옮깁니다.
2. **회계·헌금·통계 → 통계**에서 기간을 선택하고 조회합니다.
3. 먼저 **헌금자·종류 전체 보기**로 다른 종류에 입력된 내역이 있는지 확인합니다.
4. **누락 헌금 연결 확인**에서 실제 헌금인 항목을 확인해 선택·연결합니다. 정확히 일치하는 예산이 없으면 **개별 확인**으로 종류·자산 계정을 직접 지정합니다.
5. 헌금 종류를 약정헌금으로 선택해 합계를 확인합니다.

새 수입의 자동 연결, 기존 수입의 확인 연결, 중복 방지, 일괄 처리 실패 롤백을 합성 자료로 검증했습니다. 실제 XLSX와 CSV 파일을 생성·읽기·분석·가져오기한 뒤 약정헌금이 총수입과 헌금 통계에 각각 한 번 반영되는 것을 추가 검증했습니다. 실제 Chromium에서 약정/감사헌금 필터와 빈 결과의 전체 보기 복구를 검증했습니다. 전체 테스트와 빌드·서식 검증이 통과했습니다. 사용자의 PC 장부 파일은 접근하거나 변경하지 않았습니다. Windows exe 직접 실행은 이 Linux 환경에서 검증하지 못했습니다.

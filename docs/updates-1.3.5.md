# 1.3.5 기간별 그래프와 컬러 보고서

기존 **보고서** 메뉴의 주간·월간·회계 연도 결산 보고서에 적용했습니다.

- 기존 이월액·누계 현황을 유지하면서 **선택 기간의 발생액만** 집계한 그래프와 금액표를 함께 표시합니다.
- **주간**: 해당 주의 일별 수입·지출 및 헌금 그래프
- **월간**: 해당 월의 일별 수입·지출 및 헌금 그래프. 윤년과 회계 연도 경계를 반영합니다.
- **연간**: 선택한 회계 연도의 월별 수입·지출 및 헌금 그래프
- 수입은 **파랑**, 지출은 **주황**, 헌금은 **초록**으로 구분합니다. 문서 제목·표 머리글·선·예산 막대도 컬러 팔레트를 공유합니다.
- 그래프와 기간 금액표는 같은 집계 배열을 사용합니다. 거래가 없는 일자·월도 0으로 포함합니다. 헌금은 헌금 종류가 연결된 수입만 한 번 합산하며, 총수입에 포함되는 금액입니다.
- 미리보기·PDF·인쇄가 같은 문서 요소를 사용하므로 기간과 색상이 일치합니다. 컬러 지원 프린터에는 컬러 인쇄를 기본 요청합니다. 실제 출력 색상은 프린터의 지원 여부와 인쇄 대화상자 설정에 따릅니다.
- 데이터가 많으면 여러 A4 페이지로 나눕니다. 글자 크기·행 간격·한 페이지 맞춤 설정은 유지했습니다.

## 확인 방법

새 버전에서 **보고서 → 주간/월간/회계 연도 수입·지출 결산 보고서**를 선택하고 조회하세요. 월간은 조회 월을 지정합니다. PDF 저장에도 기간 그래프와 컬러가 포함됩니다.

## 검증

전체 테스트 **1,229개: 통과 1,228, 실패 0, 건너뜀 1**입니다. `test bootJar spotlessCheck`와 기존 실제 브라우저 검증이 통과했습니다.

이전 기간 이월액과 이후 거래가 주간·월간 그래프에 포함되지 않는지, 윤년 2월 29일까지 포함되는지, 연간 그래프와 원본 합계가 일치하는지 확인했습니다. 합성 장부로 주간·월간·연간 PDF를 실제 생성한 뒤 텍스트·색상·페이지 배치를 확인했습니다. 월간 보고서는 누계 현황과 기간 그래프가 다른 값으로 함께 표시되는 것도 검증했습니다.

새 DB migration이나 운영 자료 수정은 없습니다. 예시 PDF는 합성 검증 자료이며 실제 교회 장부가 아닙니다. 실제 프린터 출력과 Windows exe 직접 실행은 이 Linux 환경에서 미검증입니다.

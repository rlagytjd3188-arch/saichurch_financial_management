# 1.3.4 헌금자·차변/대변 자동 처리

## 일반 입력

헌금/수입/지출 입력에서 이름·일자·금액·예산과 통장을 입력하면 회계 계정을 자동 선택합니다. 수익·비용 계정의 직접 지정과 공동 헌금자 선택은 `직접 지정` 안으로 접었습니다.

- 이름 전체가 등록된 활성 관계자 한 명과 일치하면 자동 연결합니다. 공백 차이, 은행 거래시각과 `이름 + 약정헌금` 같은 명확한 표기도 인식합니다.
- 동명이인·부분 이름·미등록 이름은 추정하지 않습니다. 이름을 직접 입력했는데 일치하지 않으면 확인을 요청합니다. 은행 가져오기의 불확실한 이름은 미분류로 남깁니다.
- 헌금 수입은 통장 차변/헌금수익 대변, 일반 수입은 통장 차변/기타수익 대변입니다.
- 지출은 예산과 같은 이름의 활성 비용 계정이 유일하면 그 계정을 차변으로, 통장을 대변으로 선택합니다. 예를 들어 선교비는 선교비/보통예금으로 처리합니다. 해당 계정이 없으면 기타비용으로 처리합니다.
- 기존 거래를 단순 수정할 때의 명시적인 헌금·계정·통장 지정은 보존합니다. 수동 분개는 `고급 회계`에서 계속 사용할 수 있습니다.

## 은행 파일과 이미 가져온 내역

카카오뱅크 내용에서 이름을 정확히 찾으면 등록된 사람에게 연결합니다. 내용이나 메모에 헌금 종류 한 가지가 명시되어 있으면 해당 기본 헌금 예산을 선택합니다. 그 외 수입은 기타수입, 출금은 기타비용으로 남습니다.

이미 가져온 미분류 수입은 기간을 선택한 뒤 **헌금자 자동 연결**을 누르면 됩니다. 이름이 정확히 맞는 건만 연결하며 이미 사람이 지정된 내역과 마감 연도는 바꾸지 않습니다. 이 작업은 거래를 추가로 생성하지 않습니다.

은행 파일 재가져오기의 중복 검사는 사람이나 예산이 변경되었더라도 원래의 거래시각·내용·구분·금액으로 비교하도록 보완했습니다.

## 기초잔액

**거래 → 기초잔액 입력**에서 기준일·통장·기존 잔액만 입력합니다. 차변 통장/대변 이월잉여금은 자동 생성하며 수입과 헌금에는 더하지 않습니다. 기존 잔액을 이미 입력했다면 중복 입력하지 마세요.

## 검증

전체 테스트 **1,227개 중 1,226 통과, 실패 0, 건너뜀 1**입니다. 자동 헌금자 연결, 동명이인·부분 이름 제외, 자동 비용 계정, 기존 미분류 수입 연결, 은행 재가져오기 중복 방지, 기초잔액의 수입 제외를 검증했습니다. 실제 Chromium에서 회계 계정·헌금자를 직접 선택하지 않고 이름·금액으로 저장하는 흐름과 기존 화면 기능을 확인했습니다. `test bootJar spotlessCheck`가 통과했습니다.

첨부 은행 파일도 별도의 임시 DB에서 합계 보존과 30건 가져오기를 다시 확인했습니다. 운영 장부·암호는 변경하지 않았습니다. Windows exe 직접 실행은 이 Linux 환경에서 미검증입니다.

# 1.3.6 기초잔액 보고서 반영

기초잔액은 분개 장부에 저장되지만 기존 데스크톱 보고서는 수입·지출 내역만 집계해 잔액에서 빠졌습니다. 주간·월간·회계 연도 보고서가 이미 입력한 기초잔액을 읽도록 수정했습니다. **기초잔액을 다시 입력할 필요가 없습니다.**

- 보고서 시작일 이전의 기초잔액과 수입·지출 잔액은 이월액에 포함합니다. 이전 회계 연도의 잔액도 이어집니다.
- 선택 기간 안에 등록한 기초잔액은 별도 항목으로 표시하고 현재 잔액·기말 잔액에 더합니다.
- 보고서 종료일까지의 기초잔액 반영액을 별도로 표시합니다. 이후 날짜의 기초잔액은 미리 반영하지 않습니다.
- 취소 역분개가 있는 기초잔액은 상쇄합니다.
- 기초잔액은 수입·헌금·예산 집행액이나 기간별 발생액 그래프에 합산하지 않습니다. 기존 컬러 그래프와 누계 표는 유지합니다.

예를 들어 기초잔액 5,000,000원, 기간 수입 100,000원, 지출 30,000원이면 보고서 잔액은 **5,070,000원**, 기간 수입은 **100,000원**입니다.

## 적용 방법

업데이트 전 기존 앱에서 백업 파일을 만드세요. 새 버전은 별도 폴더에 풀고 백업을 복원하세요. **보고서 → 주간/월간/회계 연도 수입·지출 결산 보고서**를 다시 조회하면 반영됩니다. 기초잔액의 입력 일자가 보고서 종료일 이내인지 확인하세요.

새 DB migration이나 운영 자료 수정은 없습니다. 원본 거래의 수입·지출과 별도로 자산·순자산 분개에 기록한 기초잔액을 합산하므로 거래 분개를 이중 합산하지 않습니다.

## 검증

전체 테스트와 JAR 빌드·코드 형식 검사를 실행했습니다. 기초잔액 입력 전후 기간, 취소, 다음 회계 연도 이월과 수입·헌금 그래프의 중복 합산 방지를 검증했습니다. 합성 자료로 주간·월간·연간 PDF를 생성하고 기초잔액·기말 잔액의 텍스트와 페이지 배치를 확인했습니다.

예시 PDF는 실제 교회 자료가 아닙니다. 실제 사용자 PC의 장부와 Windows 실행파일 직접 구동은 이 Linux 환경에서 확인하지 않았습니다.

# 1.4.1 종료월 선택 입력·그래프 색상·보고서 별지

## 종료월 없이 약정 저장

약정 입력 폼이 입력칸을 잘못 조회하면서 종료월의 필수 입력을 해제하지 못하던 오류를 수정했습니다. 폼 생성 단계부터 종료월을 선택 항목으로 지정합니다.

**헌금자 → 월 약정 설정**에서 금액·시작월만 입력하고 종료월을 비워 저장할 수 있습니다. 기존 약정 이력의 **수정**에서도 종료월을 지워 계속 약정으로 바꿀 수 있습니다. 기존 약정과 새 약정의 기간이 겹치는 경우에는 기존 이력을 수정하세요.

## 그래프 색상

- 수입 막대·선은 빨간 계열, 지출 막대·선은 파란 계열로 통일합니다.
- 약정·주정·선교·감사헌금만 서로 다른 빨간색으로 표시합니다.
- 나머지 수입은 빨간 기본색, 나머지 지출은 파란 기본색입니다. 이전의 항목별 무지개 색상은 적용하지 않습니다.
- 대시보드, 브라우저 통계·보고서, 주간·월간·연간 PDF, 예산별 진행 막대에 같은 색상 기준을 적용합니다.
- 약정 실제 납부액·달성률 선도 빨간 계열입니다. 목표 기준선은 구분하기 쉬운 회색 계열 점선을 유지합니다.

색상만 변경하며 기존 거래 분류나 금액을 초기화하지 않습니다.

## 주간·월간 보고서 별지

보고서는 **요약·그래프 → 수입 내역 별지 → 지출 내역 별지** 순서이며, 수입·지출은 각각 새 페이지에서 시작합니다. 내역이 길면 같은 종류의 별지에서 다음 페이지로 이어지고 제목·기간·열 제목을 반복합니다.

내역의 열은 **일자 / 이름 / 내용 / 금액**입니다. 봉헌자·수취인이라는 열 제목을 **이름**으로 변경했습니다. 비고 열과 비고 내용은 보고서에서 제외하며 원본 거래의 비고는 보존합니다.

**보고서 → 주간/월간 보고서 → 출력 범위**에서 다음 중 하나를 선택하세요.

- **전체 (별지 포함)**: 요약·그래프와 수입·지출 별지를 함께 출력
- **요약·그래프만**: 내역 별지 제외
- **수입 내역 별지**: 수입만 인쇄·PDF 저장
- **지출 내역 별지**: 지출만 인쇄·PDF 저장

선택한 내용이 미리보기에 표시되며 **인쇄 / PDF 저장**에 동일하게 적용됩니다. 전체 출력에서는 별지의 페이지 구분을 유지하도록 한 페이지 자동 축소를 적용하지 않습니다.

## 업데이트

기존 앱에서 백업한 뒤 1.4.1을 별도 폴더에 풀고 백업을 복원하세요. 새 DB 변경은 없습니다. 기초잔액·거래·월 약정액을 다시 입력할 필요가 없습니다.

## 검증

실제 브라우저에서 종료월 없는 신규 약정 저장, 기존 종료월 삭제·재저장, 서버의 종료월 값 반영을 검증했습니다. 네 헌금의 서로 다른 빨간색, 기타 수입 기본색과 지출 파란 기본색을 확인했습니다. 주간·월간 보고서의 본문/수입/지출 페이지 분리, 비고 제외, 이름 열 제목, 독립 출력 및 PDF 페이지 배치를 검증했습니다. 실제 Windows exe와 프린터 출력은 Linux 환경에서 직접 확인하지 않았습니다.

전체 테스트 **1,243개 중 통과 1,242, 건너뜀 1, 실패 0**이며, 실제 브라우저 검증과 `bootJar spotlessCheck`가 통과했습니다. 최소 창 크기의 보고서 화면에서 출력 범위 선택과 미리보기 문서 변경도 검증했습니다.

# 1.5.2 보고서 그래프의 기간 합계

주간·월간·연도 보고서의 막대그래프 **맨 오른쪽**에 해당 기간의 합계를 추가했습니다.

- **주간 합계**: 조회한 주의 전체 수입·지출입니다. 일별 막대 뒤에 배치합니다.
- **월간 합계**: 조회한 월의 전체 수입·지출입니다. 주별 막대 뒤에 배치합니다.
- **연간 합계**: 선택 회계 연도의 전체 수입·지출입니다. 월별 막대 뒤에 배치합니다.
- 헌금 그래프에도 같은 기간의 헌금 합계를 추가했습니다.

합계 구간은 옅은 배경과 구분선으로 표시하고 이름과 금액을 굵게 표시합니다. 수입·지출 막대는 나란히 표시하며 기존 헌금별 색상을 유지합니다. 합계가 축 범위를 벗어나지 않도록 전체 막대를 기준으로 축 범위를 정합니다. 주간 10만 원·월간 50만 원 눈금 간격은 유지합니다.

합계는 보고서의 선택 기간에 발생한 거래만 포함합니다. 기초잔액·이월액과 기간 밖 거래를 더하지 않습니다. 그래프에만 합계 막대를 추가하므로 기존 금액표·상단 수입/지출·내역 별지·누계는 중복 합산되지 않습니다. 미리보기·PDF·인쇄에 같은 내용을 사용합니다.

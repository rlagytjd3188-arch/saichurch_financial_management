# 기존 교회 장부 가져오기

## 사용 순서

1. 실행 중인 앱을 종료하고 GitHub Desktop에서 Fetch origin → Pull origin을 누릅니다.
2. Start-Windows.cmd로 실행합니다. 최신 코드가 빌드됩니다.
3. 「은행내역 가져오기」 → 상단 「기존 교회 장부 가져오기」 → 「기존 장부 XLSX 선택」을 누릅니다.
4. Google Sheets에서 내려받은 원본 파일을 선택합니다. 원본 파일을 미리 수정하거나 첫 시트만 따로 뺄 필요가 없습니다.
5. 회계연도를 선택하고 각 통장의 앱 계좌를 연결합니다. 처음 사용하는 경우 시트 이름으로 계좌를 생성할 수 있습니다. 이미 있는 통장은 반드시 기존 계좌에 연결하세요.
6. 원본 건수·입출금 합계·기초잔액 후보·잔액 연속성을 검토합니다. 잔액이 불일치하면 해당 시트·행·예상 잔액·원본 잔액을 펼쳐 확인할 수 있습니다.
7. 계정 가이드 등록 여부를 확인합니다. 코드가 같은 기존 계정은 이름·유형까지 같을 때만 재사용합니다. 코드 충돌이 있으면 기존 설정을 확인하고 가이드 등록을 해제하거나 별도로 정리하세요.
8. 예산을 가져오려면 각 항목을 실제 비용 계정에 연결합니다. 연결하지 않은 항목은 제외합니다. 여러 항목을 같은 계정에 연결하면 합산합니다. 기존 예산이나 상하위 중복 예산은 덮어쓰지 않고 전체 작업을 중단합니다.
9. 확인 체크 후 가져옵니다. 여기서는 원본만 저장하며 수입·지출 분개를 자동 확정하지 않습니다.
10. 「미분류 거래」에서 분류·이체 연결을 확인한 뒤 장부에 반영합니다. 기존 내역과 날짜·종류·금액이 같고 후보 계정이 하나인 경우 분류를 추천합니다. 동일 금액의 다른 거래일 수 있으므로 반드시 확인하세요.

## 인식 구조

- 첫 행 A:D가 거래일시 / 구분 / 거래금액 / 거래 후 잔액인 모든 시트를 읽습니다.
- A:G의 날짜·입출금 구분·부호 있는 금액·잔액·거래구분·내용·메모를 보존합니다.
- H열 이후의 반복 수식과 집계표는 거래로 읽지 않습니다.
- 「계정 가이드」의 수입·비용 코드를 읽되 100 전월 잔액과 221 통장간이체는 제외합니다.
- 「예산집행」의 A1에서 예산 연도, G:I의 3~15행에서 지출예산을 읽습니다. 심방비/급여 등 명칭 차이는 사용자가 직접 연결합니다. 수입 목표는 현재 비용예산 모델에 억지로 넣지 않습니다.
- 「내역」은 분류 추천 참고용입니다. 「정리한 것」·「시트19」 등 집계/월간 표와 함께 별도 거래로 반영하지 않습니다. 통장에 없는 현금·별도 조정 거래는 수동 입력이 필요합니다.
- 0원 거래는 제외 목록에 표시합니다. 수식 오류·입출금 부호 모순·잘못된 날짜 등 오류 행이 있으면 전체 가져오기를 막습니다.

## 중복·무결성

계좌·날짜·시간·입금·출금·적요·잔액 fingerprint가 이미 있으면 미반영 원본도 중복 생성하지 않습니다. 같은 파일의 다른 연도는 따로 가져올 수 있습니다. 기존 수동 입력과 은행 원본의 중복은 자동 확정할 수 없으므로 도입 기간과 계좌를 확인하세요.

한 연도의 계정·계좌·기초잔액·예산·은행 원본 저장은 단일 DB 트랜잭션입니다. 어떤 단계에서든 충돌하면 전부 롤백합니다. 기초잔액 자동 등록은 원장과 은행 원본이 모두 비어 있고 선택한 모든 통장 잔액 연속성이 일치할 때만 허용합니다. 첫 거래 잔액에서 역산한 값은 후보이며 실제 연초 잔액인지 사용자가 확인해야 합니다. 이는 자동 연말 마감·이월 기능이 아닙니다.

업로드 XLSX는 data/workbook-previews의 임의 UUID 파일로 PC에 보관합니다. 반영 시 서버가 해당 원본을 다시 읽고 검증하며, 클라이언트에서 조작한 행이나 합계는 신뢰하지 않습니다. 원본 파일을 삭제하면 해당 미리보기는 다시 업로드해야 합니다. 외부 조회에서는 업로드·가져오기를 차단하며 XLSX 원본 파일은 게시하지 않습니다. 전체 data 폴더 백업에는 이 파일도 포함됩니다.

## 검증 범위

실제 제공 파일은 로컬 임시 DB에서 분석 및 가져오기·재가져오기를 검증했습니다. 실제 금액과 개인 이름, 원본 XLSX, 생성된 DB는 소스 저장소에 포함하지 않습니다. 자동 테스트에는 합성 샘플만 사용합니다. Windows 자체 실행 검증은 별도로 필요합니다.

일반 은행파일의 「파일 선택」이나 드래그 영역으로 이 장부를 올려도 통장 시트를 자동 인식해 기존 교회 장부 검토 화면으로 연결합니다. 빈 병합 셀은 빈 값으로 읽고, 수식 결과가 없는 금액은 0원으로 임의 보정하지 않습니다.

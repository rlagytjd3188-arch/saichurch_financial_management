# 사이교회 재무관리 1.3.1

사용자가 요청한 여섯 가지 변경을 반영했습니다.

1. **월간 보고서**: 기존 보고서 메뉴에서 `월간 회계 결산 보고서`를 선택하고 `조회 월 (YYYY-MM)`에 월을 입력합니다. 전월 이월액, 해당 월 수입·지출·차액, 월말 잔액, 예산별 누계와 상세 내역을 표시합니다. 미리보기·인쇄·PDF 저장을 지원합니다. 윤년의 2월과 회계 연도의 일부만 포함된 달도 처리합니다.
2. **프로그램 정보**: 이메일 표시와 이메일 복사 버튼을 삭제했습니다. 원본 MIT 라이선스 문서는 보존했습니다.
3. **안내 문구 삭제**: 요청한 축복 문구와 무료 재정 도구 소개 문구를 프로그램 정보 화면에서 삭제했습니다.
4. **수입·지출 예산**: 수입 8개(주정·약정·감사·선교·절기·특별·기타헌금, 기타수입), 지출 7개(사역·예배·선교·교육·관리·인건비·기타비용)를 준비합니다. 실제 계획액을 추정하지 않아 기본 금액은 **0원**입니다. 예산 관리에서 실제 연간 계획액을 입력하세요. 기존 예산의 이름·계층·금액은 덮어쓰지 않습니다. V5 migration은 마감되지 않은 기존 연도에 없는 항목만 추가하고, 새 회계 연도 및 예산 복사에도 누락 항목을 준비합니다.
5. **모든 양식에 예시**: 예산·수입/지출·관계자의 XLSX와 CSV에 각각 두 행의 작성 예시를 넣었습니다. 예산과 거래 양식에는 수입·지출을 모두 넣습니다. 관계자·거래의 이름은 가상의 예시입니다. 실제 자료로 바꾼 뒤 가져오세요. 양식 내려받기는 운영 장부에 예시 거래를 생성하지 않습니다.
6. **로고 아이콘**: 첨부 로고를 바탕으로 아이콘용 이미지를 정리하고 Windows ICO와 16~256픽셀 창·작업표시줄 아이콘을 교체했습니다. Windows jpackage 빌드에도 새 아이콘을 사용합니다. 이 대화의 Windows ZIP에는 실제 exe 아이콘 리소스도 교체되어 있습니다.

## 실행·업데이트

새 Windows ZIP을 **별도 폴더**에 압축 해제한 뒤 `ChurchSteward.exe`를 실행합니다. Java가 포함되어 있으므로 별도 Java·Node.js 설치가 필요 없습니다. 기존 앱을 사용했다면 앱에서 백업한 뒤 새 폴더에서 복원하세요. `data/`와 암호화 설정 `application.yml`은 보존해야 합니다.

이 환경에서 제공하는 Windows ZIP은 체크섬 검증한 원본 Windows 런처의 아이콘 리소스, 수정 JAR, 공식 Java 런타임을 조합합니다. 런처의 원본 파일 버전 메타데이터는 유지되며 앱 자체 버전은 1.3.1입니다. GitHub Actions Windows 빌드는 런처까지 새 버전으로 생성합니다. Linux 작업환경이므로 Windows exe의 직접 실행은 미검증입니다.

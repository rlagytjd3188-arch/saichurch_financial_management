# 1.5.0 월 약정 미납 표시·외부 교회·보고서 그래프

## 약정헌금 미납

헌금자 목록의 이름 옆 **메모** 칸에 빨간 **약정헌금 미납** 박스를 표시합니다.

- 조회 종료일이 속한 달에 유효한 월 약정액이 있고, 그 달 월초부터 기준일까지 확인된 개인 납부액이 **0원**이면 표시합니다.
- 일부라도 납부하면 표시하지 않습니다. 이전 달에 납부했어도 해당 달에 납부가 없으면 표시합니다.
- 약정이 시작되기 전이나 종료된 달에는 표시하지 않습니다. 납부 취소도 집계에 반영합니다.
- 기존 메모를 덮어쓰지 않으며, 표시를 연락처 메모에 영구 저장하지 않습니다. 조회 월을 바꾸면 다시 계산합니다.
- 공동헌금은 확인된 개인 배분만 납부액으로 인정합니다. 미배분 금액을 임의로 나누지 않습니다.

## 외부 교회 명부

**회계·헌금·통계 → 외부 교회 → 외부 교회 추가**에서 교회명과 통장 입금자명을 등록하세요. 여러 입금자명은 쉼표로 구분합니다.

- 교회명·등록한 입금자명이 정확히 일치하는 **수입**을 자동 연결합니다. 부분 이름이나 여러 교회가 일치하는 경우는 추정하지 않습니다.
- 등록할 때 마감하지 않은 회계 연도의 기존 수입을 찾아 연결합니다. 이후 일반 입력·엑셀 가져오기에서도 같은 기준을 사용합니다.
- **기존 내역 자동 연결**로 다시 확인할 수 있고, 이름이 다르게 찍힌 거래는 **거래 직접 연결**로 지정할 수 있습니다.
- 직접 연결을 해제하면 그 거래는 자동 연결 대상에서 제외합니다. 마감한 연도의 거래는 변경하지 않습니다.
- 교회명 변경 시 이전 이름은 입금자명으로 보존합니다. 비활성화하면 새 자동 연결을 중지하고 이미 연결한 기록은 유지합니다.
- 명부에서 교회별 조회 기간 합계와 건수, 아래에서 연결된 거래 내역을 확인합니다.

연결된 거래의 비고에는 기존 내용 뒤에 **외부교회헌금**을 표시합니다. 기존 비고 원문과 금액·예산은 보존합니다. 수정 화면과 원본 CSV 내보내기는 기존 비고 원문을 사용하며, 전체 백업에는 교회 명부·연결도 함께 보존됩니다. 1.4.1에서 제외한 보고서 별지 비고 열은 다시 추가하지 않습니다.

외부 교회 헌금은 수입·헌금 그래프에서 **주황갈색**으로 구분합니다. 개인 약정헌금의 납부액에는 포함하지 않습니다. 취소 거래는 합계에서 제외하며, 과거 REVIEW 거래는 회계 연결을 확인해야 원장 기준 그래프에 반영됩니다.

공개용 화면에는 외부 교회별 이름·입금자명·메모·거래 목록을 제공하지 않습니다. **외부교회헌금 합계**만 제공합니다.

## 주간·월간 보고서 그래프

- **월간**: 일요일~토요일 기준의 주별 합계입니다. 첫·마지막 주는 선택한 월 안의 날짜만 포함합니다. 세로축은 **50만 원** 간격입니다.
- **주간**: 기존 일별 가로축을 유지하고 세로축을 **10만 원** 간격으로 표시합니다.
- 수입·지출·헌금 막대 위에 쉼표와 원 단위가 포함된 실제 합계 금액을 표시합니다. 분류별 색상과 별지는 유지합니다.
- 세로축 금액은 정수 만원 단위로 표시합니다. 금액이 큰 경우 그래프 높이를 늘리고, 글자가 겹치는 경우 눈금 단위는 유지하며 일부 눈금 글자만 생략합니다.
- 월간 기간별 금액표도 그래프와 같은 주별 합계로 표시합니다. 거래별 실제 날짜는 별지에 유지합니다.
- 주간·월간 약정 목표·납부액 그래프에도 같은 금액 눈금 간격을 적용합니다. 월간 약정 그래프는 주말 기준 **월 누계 납부액**과 월 약정 전액을 비교합니다. 달성률 그래프는 원 단위와 구분해 %로 표시합니다.

## 업데이트와 검증

기존 앱에서 백업한 후 1.5.0을 별도 폴더에 풀고 백업을 복원하세요. V8은 외부 교회 명부와 거래 연결 필드를 추가합니다. 기존 금액·기초잔액·약정을 초기화하거나 다시 입력할 필요가 없습니다. 업데이트 후 웹 화면을 새로고침하세요.

월별 미납 표시 전환, 기존·신규 외부 교회 연결, 이름 변경, 수동 연결·해제, 지출 제외, 취소·합계 보존, 개인 약정 실적 제외, 공개 정보 제외를 검증합니다. 주별 합계와 월 총액 일치, 50만/10만 원 눈금, 금액 주석을 검증하고 실제 브라우저·Swing·PDF 화면을 확인합니다. 실제 Windows exe와 프린터 출력은 Linux 환경에서 직접 확인하지 않았습니다.

전체 테스트 **1,247개 중 통과 1,246, 건너뜀 1, 실패 0**, 실제 브라우저 검증, `bootJar spotlessCheck`가 통과했습니다.

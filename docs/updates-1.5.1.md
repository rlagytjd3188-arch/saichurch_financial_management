# 1.5.1 그래프 색상과 범례 정리

대시보드, 웹 통계, 주간·월간·연도 보고서의 그래프 분류를 같은 기준으로 표시합니다.

| 분류 | 색상 |
| --- | --- |
| 약정헌금 | 빨강 |
| 주정헌금 | 초록 |
| 선교헌금 | 보라 |
| 감사헌금 | 노랑 |
| 외부교회헌금 | 주황 |
| 기타수입 | 회색 |
| 지출 | 파랑 |

기본색이 같은 수입 분류는 **기타수입**, 모든 지출 분류는 **지출** 하나로 합쳐 표시합니다. 물품/시설관리·월세·식사비용 등 같은 색으로 나열되던 세부 범례는 그래프에서 제외합니다. 금액은 합산하므로 전체 수입·지출·헌금 합계는 보존됩니다. 약정·주정·선교·감사헌금 이름 앞의 반복되는 ‘헌금수입 /’ 문구도 줄였습니다. 해당 기간에 전혀 금액이 없는 웹 그래프 계열은 범례에서 숨깁니다.

거래, 예산 분류, 헌금 종류, 자동 분개·헌금 연결 기준과 보고서의 거래별 내역은 보존합니다. 그래프의 기타수입·지출을 누르면 합쳐진 거래 전체를 확인할 수 있습니다. 개인 약정 납부액과 달성률 그래프도 약정헌금과 같은 빨간색을 사용하며 목표는 회색 점선으로 구분합니다.

업데이트: 기존 프로그램에서 백업하고 1.5.1을 새 폴더에 풀어 복원하세요. 웹 화면은 새로고침하세요. 데이터 초기화나 재입력은 필요하지 않습니다.

다른 기타헌금이 같은 달에 존재하는 경우 월별 그래프의 금액을 합산하도록 수정했습니다. 합쳐진 범례·월 합계·공개 화면 합계·기존 예산명 보존·하위 예산의 자동 헌금 연결을 검증하며 실제 브라우저와 PDF를 확인합니다. Windows 실행파일과 프린터 출력은 Linux 환경에서 직접 실행하지 않았습니다.

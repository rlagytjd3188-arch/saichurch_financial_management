# 1.3.7 대시보드와 잔액 화면의 기초잔액 반영

메인 대시보드가 수입에서 지출만 뺀 차액을 보여주던 문제를 수정했습니다. 데스크톱의 잔액 계산을 공통 서비스로 묶어 보고서와 다른 값이 표시되지 않도록 했습니다. 이미 입력한 기초잔액을 다시 입력할 필요는 없습니다.

## 화면별 점검과 변경

| 화면 | 반영 내용 |
| --- | --- |
| 메인 대시보드 | **기초잔액·이월액** 카드를 추가하고, 기존 차액 카드는 이를 더한 **기말 잔액**으로 변경했습니다. 기초잔액 반영액도 함께 표시합니다. |
| 회계 연도 관리 | 마감 여부와 관계없이 **기초잔액·이월액**, **기말 잔액** 열을 표시합니다. 좁은 창에서는 가로 스크롤로 볼 수 있습니다. |
| 주간·월간·연간 보고서 | 1.3.6의 반영을 유지하고 대시보드와 같은 기초잔액·이월액 계산 서비스를 사용합니다. |
| 브라우저 대시보드 | 기존 현금·예금 잔액, 자산, 순자산에 기초잔액이 포함됨을 검증했습니다. |
| 재무상태표·재무상태 보고서·외부 조회 | 같은 원장 집계를 사용합니다. 기초잔액 포함 자산·순자산과 공개 집계 값을 대조했습니다. |
| 수입·지출 조회 요약 | 검색된 거래의 차액이라는 뜻을 명확히 하려고 **조회 차액**으로 표시하고 잔액 안내를 추가했습니다. |
| 수입·지출, 헌금, 예산, 기간 그래프 | 실제 발생액이므로 기초잔액을 수입이나 헌금으로 더하지 않습니다. |

대시보드는 **선택한 회계 연도 종료일** 기준입니다. 기초잔액·이월액에 해당 연도의 총 수입을 더하고 총 지출을 뺀 값이 기말 잔액입니다. 예를 들어 기초잔액 5,000,000원, 수입 100,000원, 지출 30,000원이면 기말 잔액은 **5,070,000원**입니다.

브라우저에서 입력한 후 데스크톱 대시보드로 돌아오면 다시 조회합니다. 제목 오른쪽 **새로고침** 버튼으로도 갱신할 수 있습니다.

회계 연도 목록의 기존 총 수입·총 지출·차액은 마감 시 저장한 기록입니다. 새 기말 잔액 열은 기초잔액·이월액을 포함한 조회값이며, 저장된 마감 기록을 덮어쓰지 않습니다. 이전 회계 연도의 잔액은 한 번만 이월하고, 종료일 이후 기초잔액은 앞선 연도에 포함하지 않으며, 취소 역분개는 상쇄합니다.

## 업데이트

기존 앱에서 백업한 후 1.3.7을 별도 폴더에 풀고 백업을 복원하세요. **기초잔액 재입력이나 데이터 초기화는 필요 없습니다.** DB 구조나 운영 자료는 변경하지 않습니다.

## 검증

기초잔액만 있는 경우, 실제 수입·지출과 함께 있는 경우, 취소, 마감·마감 취소, 다음 연도 이월, 이후 연도 기초잔액의 제외를 검증했습니다. 대시보드·회계 연도 목록·보고서·브라우저 및 공개 집계의 금액을 비교하고, 기초잔액이 수입·헌금·예산·기간 그래프에 중복 합산되지 않는지도 확인했습니다.

대시보드 화면을 실제 Swing 구성 요소로 만들고 최소 폭에서 카드 표시와 새로고침을 검증했습니다. 전체 Java 테스트 **1,236개 중 통과 1,235, 건너뜀 1, 실패 0**, 실제 브라우저 검증, 배포용 JAR 빌드와 형식 검사가 통과했습니다. 검증 자료는 합성 장부이며 Windows 실행파일 직접 구동은 Linux 환경에서 확인하지 않았습니다.

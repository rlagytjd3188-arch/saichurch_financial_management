# 1.3.3 은행 파일 가져오기·선택 삭제·간단한 설정

## 카카오뱅크 엑셀 가져오기

데이터 관리 → 수입/지출 → 가져오기에서 파일을 고르고, 암호가 있으면 입력합니다. 안내문이 앞에 있는 카카오뱅크 표도 자동 인식합니다. `거래일시 / 구분 / 거래금액 / 거래 후 잔액 / 거래구분 / 내용 / 메모` 열을 읽습니다.

- 안내문과 빈 줄을 제외하고 입금·출금을 구분합니다. 음수 출금은 양의 지출 금액으로 바꿉니다.
- 거래 후 잔액은 거래 금액이나 기초잔액으로 더하지 않습니다. 내용·거래시각·잔액·메모를 보존합니다.
- 은행 파일에는 예산과 실제 헌금자 정보가 확정되어 있지 않아 **입금은 기타수입, 출금은 기타비용, 거래상대는 통장거래(미분류)**로 준비합니다. 헌금 종류나 실제 사람을 임의로 추정하지 않습니다. 가져온 뒤 확인하여 변경할 수 있습니다.
- 분석·내역 확인·백업·저장을 거쳐 적용하며, 파일을 여는 것만으로 거래가 저장되지 않습니다. 재가져오기 시 중복 의심 거래를 표시합니다.
- 일반 엑셀·CSV의 기존 가져오기 기능도 유지합니다.

## 간단한 읽기 화면

단계를 `파일 선택 → 읽기 확인 → 분류 확인 → 내역 확인 → 저장`으로 바꿨습니다. 읽기 확인에서는 자동 인식 결과를 먼저 보여주고, 복잡한 열 지정은 **고급 설정 펼치기** 안에 둡니다. 자동 인식에 필요한 값이 없으면 설정을 열어 확인할 수 있습니다.

## 여러 내역 한 번에 삭제

- **기존 프로그램**: 건별 보기와 예산별 보기에서 행을 차례로 클릭하면 여러 건을 고를 수 있습니다. 다시 클릭하면 해제합니다. 전체 선택·선택 해제 버튼도 추가했습니다. 선택 후 삭제 버튼을 누릅니다.
- **브라우저**: 거래·헌금 내역의 체크박스로 선택한 뒤 **선택 삭제**를 누릅니다. 전체 선택과 선택 건수 표시도 제공합니다. 공동 헌금처럼 같은 거래가 여러 행에 보여도 원본은 한 번만 처리합니다.
- 기존의 마감 제한과 관리자 권한을 유지합니다. 삭제 시 원본을 보존하고 역분개로 취소합니다.

## 검증

전체 테스트 1,221개 중 **1,220 통과, 실패 0, 건너뜀 1**이며 `test bootJar spotlessCheck`가 통과했습니다. 실제 Chromium에서 두 건을 체크해 한 번에 삭제하는 흐름을 확인했습니다. 가상 데스크톱에서도 Ctrl 없이 두 행을 클릭해 동시에 선택됨을 확인했습니다.

첨부 원본은 별도로 **임시 H2 DB**에 30건 모두 가져와 입금·출금 합계 보존과 중복 재가져오기 감지를 확인했습니다. 원본 파일은 수정하지 않았습니다. 첨부 파일과 암호·실제 거래 자료는 소스 및 실행 ZIP에 포함하지 않았습니다.

Windows 실행본에는 Java가 포함됩니다. 기존 앱에서 백업한 뒤 새 버전을 별도 폴더에서 실행하고 백업을 복원하세요. Windows exe의 직접 실행은 이 Linux 환경에서 미검증입니다.

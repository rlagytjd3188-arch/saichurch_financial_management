# 1.4.0 분류별 그래프와 월 약정헌금

## 분류 색상

수입·지출 막대는 **예산의 1차 분류**별로 구분합니다. **헌금수입은 2차 분류**까지 구분합니다. 더 깊은 항목은 지정된 단계로 합산하며, 기존 예산이나 거래의 분류를 수정하지 않습니다.

- 대시보드 월별 수입·지출, 주간·월간·연간 보고서의 기간 그래프, 브라우저 대시보드·통계·보고서에 적용합니다.
- 같은 월의 수입과 지출 막대는 나란히 유지하고 각 막대 안을 분류별 색으로 나눕니다. 막대 높이는 기존 수입·지출 합계와 같습니다.
- 헌금 그래프는 헌금 종류별로 나눕니다. 개인별 헌금 막대도 헌금 종류별로 나눠 표시합니다.
- 데스크톱·PDF·브라우저·SVG에서 같은 분류는 같은 색을 사용합니다. 범례와 금액표를 함께 제공합니다.
- 예산 집행 현황의 분류별 진행 막대도 같은 색을 사용합니다.
- 기존 기본 예산처럼 주정헌금·약정헌금 등이 각각 최상위인 경우에도 헌금 종류별로 표시합니다. 헌금수입의 세부 예산으로 등록한 거래는 2차 헌금 종류를 자동 연결합니다.
- 기초잔액은 발생한 수입이나 헌금이 아니므로 기간 그래프에 합산하지 않습니다.

## 월 약정액 입력

1. **회계·헌금·통계 → 헌금자 → 월 약정 설정**을 엽니다.
2. **매월 약정액, 시작월**을 입력합니다. 계속 약정하면 종료월은 비워 둡니다.
3. 종료월까지 약정에 포함합니다. 같은 사람의 약정 기간은 겹칠 수 없습니다.
4. 금액이 변경되면 이전 약정의 종료월을 지정한 뒤 새 시작월로 추가합니다. 과거 월의 약정액이 유지됩니다.
5. 잘못 입력한 약정은 **기존 약정 이력 → 입력 취소**로 취소할 수 있습니다. 실제 헌금 납부 내역은 유지합니다.

월 약정은 수입 거래와 별도로 저장합니다. 약정액 입력으로 수입·헌금·통장잔액이 증가하지 않습니다. 헌금자를 비활성화해도 이미 약정한 기간이 임의로 바뀌지는 않으므로, 약정 종료 시 종료월을 지정하세요.

## 목표와 납부액

- **목표(100%)**: 해당 월에 유효한 모든 사람의 월 약정액 합계
- **실제 납부**: 회계 연결이 확인된 `약정헌금` 수입의 실제 금액
- **달성률**: 실제 납부 ÷ 목표 × 100
- 초과 납부는 100%를 넘겨 표시합니다. 약정 목표가 없으면 비율 대신 **약정 없음**으로 표시합니다.
- 개인별 납부액은 확인된 개인 배분만 반영합니다. 미배분 공동헌금은 전체 납부액에 한 번만 포함하고 개인 실적으로 추정하지 않습니다.
- 일반 헌금, 취소한 거래, 기초잔액은 약정헌금 납부액에 합산하지 않습니다.
- 과거 가져오기 자료 중 회계 연결·헌금 종류가 확인되지 않은 거래는 기존 **누락 헌금 연결 확인**에서 약정헌금인지 확인해야 합니다.
- 선납·늦은 납부는 실제 입금한 월에 반영합니다. 이전·다음 월의 약정으로 임의 배분하지 않습니다.

**헌금자**와 **헌금 관리·통계**에서 개인별 기간 목표액, 실제 납부액, 달성률을 확인할 수 있습니다. 전체 납부액에는 미배분 금액도 포함하므로 개인별 납부액의 합과 차이가 나면 미배분 금액을 확인하세요.

## 대시보드와 보고서

- 메인 대시보드의 월별 수입·지출 그래프에 **약정 목표액(100%) 점선**을 추가합니다.
- 옆의 **약정헌금 달성률** 탭에는 **100% 기준 점선**과 **실제 달성률 실선**을 표시합니다. 예산 현황은 옆 탭에서 확인할 수 있습니다.
- 브라우저 대시보드·보고서에는 전체 목표액·납부액 요약, 목표와 실제 납부액 그래프, 100%와 실제 달성률 그래프를 함께 표시합니다.
- 주간·월간·연간 PDF·인쇄 보고서에도 약정 목표·납부액, 달성률 그래프와 월별 금액표를 넣습니다.
- 원 단위 금액 그래프와 % 단위 달성률 그래프는 구분해 표시합니다.

약정은 월 단위이므로 **주간 보고서는 종료일이 속한 월의 월초부터 기준일까지의 납부액**을 그 달의 월 약정 전액과 비교합니다. 브라우저에서 여러 달을 선택하면 약정 집계는 첫 선택 월의 월초부터입니다. 일반 수입·지출 기간 그래프는 계속 선택한 기간의 발생액만 표시합니다. 데스크톱 대시보드는 선택 회계 연도 전체를 조회합니다.

공개용 화면에는 개인별 약정액·이름·ID·약정 이력을 제공하지 않습니다. 공개 그래프의 임의 예산명은 기존 정책에 따라 고정 공개 분류로 합산합니다.

## 업데이트와 검증

업데이트 전 기존 앱에서 백업한 뒤 새 버전을 별도 폴더에 풀고 백업을 복원하세요. V7은 월 약정 이력 테이블만 추가합니다. 기존 기초잔액·거래·예산을 다시 입력하거나 초기화할 필요가 없습니다.

분류별 합계 보존, 헌금 2차 분류, 색상 일치, 실제 가져오기 자료의 헌금 연결, 개인별 배분, 미배분 공동헌금 중복 방지, 월 약정 변경 이력, 취소, 초과 납부, 목표 없는 납부, 주간 월 누계, 공개 개인정보 제외를 검증합니다. 합성 자료로 Swing 대시보드와 PDF를 렌더링하고, 실제 브라우저에서 월 약정 등록·개인별 달성률·목표선·분류 색상·모바일·공개 화면을 확인합니다. Windows exe 직접 구동은 Linux 환경에서 확인하지 않았습니다.

전체 테스트 **1,240개 중 통과 1,239, 건너뜀 1, 실패 0**, 실제 브라우저 검증과 `bootJar spotlessCheck`가 통과했습니다.
